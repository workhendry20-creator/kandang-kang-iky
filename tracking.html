Live Digital Monitoring System

Pantau Dombamu Secara Transparan
Kapan Saja & Di Mana Saja

Setiap domba qurban, aqiqah, dan tabungan di Kandang Kang Iky memiliki catatan rekam medis, kurva kenaikan bobot harian, serta riwayat ransum pakan berbasis ID unik domba yang dapat Anda akses secara digital.

Aplikasi Resmi Sahibul Qurban

Portal Web Pantau Dombamu

Akses langsung dashboard pemantauan domba melalui aplikasi web interaktif kami. Cukup masukkan ID domba dan nomor telepon terdaftar untuk melihat status, bobot terkini, dan perkembangan terkini.

💡 Masukkan ID domba Anda (misal: KKY-00XX) lalu tekan Enter atau klik Lacak Ternak.

Tanya ID Ternakmu ke Admin

Fitur Monitoring Live:

  • ✓ Riwayat Bobot Real-Time: Grafik kenaikan ADG (Average Daily Gain) mingguan.
  • ✓ Buku Kesehatan Ternak: Catatan vaksinasi, obat cacing, dan sertifikasi syariat.
  • ✓ Log Formulasi Pakan: Transparansi ransum pakan Complete Feed silase limbah lokal.
  • ✓ Dokumentasi Domba: Update visual rutin kondisi domba di kandang.
⚖️

Penimbangan Presisi

Data timbang akurat menggunakan timbangan digital bersertifikasi setiap 2 minggu sekali demi memastikan domba Anda mencapai target bobot akad.
